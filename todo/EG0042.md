Split out of EG0041's refinement (owner 2026-11-14: "wire form-session in"). EG0041 makes loadFromFile refuse any connector outside the dispatch set. The 3 CodiMD ops in config.example/operations.yaml (codimd.notes, codimd.note, codimd.search) use `connector: form-session`, and tests load that file, so EG0041 waits for this todo.

Facts (checked 2026-11-14, master 1a6521b):
- internal/connectors/formsession/connector.go implements Login (POST <base>/login, form email+password, keeps the `connect.sid` cookie) and Execute (sends the request with that cookie, body cap 20 MiB).
- It is not in the dispatch chain in internal/server/server.go (executeOp, ~568-585), and .ai/CONNECTORS.md:42-44 says so. Today a call to such an op falls through: empty body, status 0, audited as allow.
- One Connector instance holds a single session cookie and base URL in plain fields: no per-workspace/site separation, no locking, no re-login when the session expires.
- No config (config.example or local) has a `codimd` site; the example ops are the only users.
- Existing credential pattern for user+password: the email connector reads `user` from the site environment and the password via `secret_ref` through secrets.ResolveWithWorkspaceCheck (server.go executeEmailConnector). config.Environment already has base_url, user, secret_ref, cookie_secret_ref, proxy_host, insecure_skip_verify, requires_tunnel.
- The race detector works on this machine (CGO_ENABLED=1, gcc on PATH); EG0006 used `go test -race` before.

Owner decisions (2026-11-14): wire form-session in (not remove the example ops); prove it with tests against an httptest server only, no live CodiMD instance.

For the design step: form-session as its own executor vs an auth mode of http-rest that reuses its request building (path template, query, body_template, headers, proxy, tunnel, response shaping); the credential shape (user + secret_ref like email, or a stored cookie via cookie_secret_ref with no login); where the per workspace/site/env session cache lives and how it is locked; which re-login signal (401, 302 to /login) CodiMD gives.
