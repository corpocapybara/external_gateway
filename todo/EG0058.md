  - "A line carrying leakcheck:allow has no hits, and so does a line equal (after trimming spaces) to a line of the -allow FILE (one exact line per line, # comments and blank lines ignored; a missing or unreadable FILE is an error)."
  - "Output: one line per hit naming the surface (blob, path, message, identity, tag, note), the commit (and the path and line number for a blob line) and the matched terms, then a final count line; exit 0 with no hit, 1 on any hit or error (fail closed, as pre-commit), 2 on a usage error."
