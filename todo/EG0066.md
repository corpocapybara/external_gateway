Notes from the EG0035 project review, area 6 (docs/review/2026-11-project-review.md, R13). Split from EG0057.

Facts checked 2026-11-20: `git grep -i -E 'expvar|pprof|prometheus|/metrics' -- '*.go'` has no hits; per-request
latency exists only as latency_ms in the audit line (internal/audit/logger.go Record), read by nothing.

Owner decision 2026-11-20: expose metrics as admin-token `GET /admin/metrics` JSON (admin endpoints fail closed
when admin_token_sha256 is unset). Not a periodic service-log line (that would need EG0065), not an agent-token
endpoint.

Code facts (2026-11-20): op requests go through `executeOp` in internal/server/server.go (allow audited by
`s.auditLog.LogAllow` with `latency`, denials through `writeDeny` / `writeUnknownOp`); `handleDryRun` executes
nothing. Admin routes are the `switch parts[0]` in `handleAdmin`, guarded by `authenticateAdmin`.
golang.org/x/sys v0.50.0 has `windows.GetProcessTimes` and the Toolhelp32 process snapshot but no
GetProcessMemoryInfo (needs a lazy psapi/kernel32 proc). Platform split pattern:
internal/connectors/localservice/adapters_windows.go + adapters_other.go.
