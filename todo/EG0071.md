Found 2026-11-20 while delivering EG0066 (its A7 runs `go test -race ./internal/server/`).

On master 3d2ea95, `go test -race -count=1 ./internal/server/ -run TestEmailResponse` fails both TestEmailResponseShaped
and TestEmailResponseNoAllowFieldsUnchanged with "race detected during execution of test". One side of the race is
the deferred call in `email.(*Connector).ReadMessage` (internal/connectors/email/connector.go, the `defer` near the
top of ReadMessage) reached via executeEmailConnector -> withEmail; the other is go-imap v1.2.1 write.go (bufio
writer) in another goroutine. The race is in production code paths (connector), so it may also hit live IMAP calls.
Without -race all tests pass. Repro: the command above (CGO_ENABLED=1, gcc on PATH).
