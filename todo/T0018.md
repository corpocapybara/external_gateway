Found in T0003 review (correctness, design and adversarial notes, 2026-11-11). checkJiraFields (internal/policy/registry.go) accepts an op whose body_template lacks {{fields}} (fields then goes to the query string and the constraint is cosmetic) or whose fields param has no default while the template uses {{fields}} (an omitted fields renders "fields":, invalid JSON, upstream 400). Proposed acceptance: loadFromFile refuses both, with a TestJiraFieldsConstraintLoadErrors case each.
